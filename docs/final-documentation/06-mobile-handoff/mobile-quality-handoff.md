# Mobile Quality Handoff

[Back to Index](../README.md)

Mobile quality screens should support:

- RFI list and detail.
- Checklist stages and current approval level.
- Stage submission and approval actions only when backend allows.
- Pour clearance and pour card buttons based on backend visibility/activation fields.
- Attachments, photos, remarks, signatures, and generated PDF preview/download.
